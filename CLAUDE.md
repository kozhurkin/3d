# 3d

## Сборка
- `index.html` — собранный файл: приложение `src/app.html` (с модулями `src/js/` и панелями `src/panels/`) вшито строкой в `src/shell.html`. Руками его не править: все правки только в `src/`.
- После любой правки в `src/` сразу запускать `npm run build` и проверить в Node, что изменение попало в `index.html`. Пользователь смотрит результат в `index.html`.
- Проверка: `npm run check` (приложение в Node с заглушкой THREE). Проверки — в `tools/smoke/<часть>.js` (`app`, `kitchen`, `living`, `bath`, `hall`, `flight`, `walk`), обвязка — в `harness.js`; для правки одной комнаты хватает `npm run check -- <часть>`, перед коммитом — полный прогон. Новое поведение — новые проверки в файл своей части. Часть-папка (`tools/smoke/kitchen/`, `tools/smoke/living/`) — файл на предмет, как в коде; для правки одного предмета хватает `npm run check -- <часть>/<предмет>`, новый файл — строкой в её `index.js`. В коде для страницы (`p.run(...)`) — помощники `tt` (`harness.js`: `PAGE_KIT`): `tt.fur()` (мебель вида, а не `VIEWS.kitchen.furniture()`), `tt.item('sofa')`, `tt.parts(g, q=>…)`, `tt.box(ps,'xzy')`, `tt.mm(v)`, `tt.doors(g)`; обходы и min/max вручную не писать.

## Устройство
- Одна сцена квартиры, вкладки — её виды (`views.js`: `VIEWS`, `addView`, `showView`). Размеры стен — `A` в `apartment.js`, правятся только на «Планировке» (`plan.js`); комнаты берут их оттуда.
- Модули — обычные скрипты страницы с общей областью видимости, порядок — в `src/app.html`. Модули комнат (папки `src/js/rooms/<комната>/`, прихожая — `rooms/hall.js`) обёрнуты в IIFE (папку оборачивает сборка): имена внутри у них совпадают (`P`, `computeParts`, `build`…). Общее для комнат — в `rooms/common.js` (`roomKit`); правка, одинаковая для всех комнат, делается там.
- Комната «Кухня» на плане одна, но код её поделён: `rooms/kitchen/` — сама кухня у кухонной стены (шкафы, техника, обеденный стол, стулья, светильник, полки над столом), `rooms/living/` — остальное в комнате (рабочее место: письменный стол, кресло, витрина; жилая часть: шкаф, антресоли, диван, полка над ним, стеллажи). `living` грузится перед кухней, строится вместе с ней в её осях и берёт у неё нужное через `living.attach`. Обе папки — по файлу на предмет (карта — в README).
- Карта файлов — в README.
