# 3d

## Сборка
- `index.html` — собранный файл: приложение `src/app.html` (с модулями `src/js/` и панелями `src/panels/`) вшито строкой в `src/shell.html`. Руками его не править: все правки только в `src/`.
- После любой правки в `src/` сразу запускать `npm run build` и проверить в Node, что изменение попало в `index.html`. Пользователь смотрит результат в `index.html`.
- Проверка: `npm run check` (`tools/smoke.js`: приложение в Node с заглушкой THREE). Новое поведение — новые проверки.

## Устройство
- Одна сцена квартиры, вкладки — её виды (`views.js`: `VIEWS`, `addView`, `showView`). Размеры стен — `A` в `apartment.js`, правятся только на «Планировке» (`plan.js`); комнаты берут их оттуда.
- Модули — обычные скрипты страницы с общей областью видимости, порядок — в `src/app.html`. Модули комнат (`src/js/rooms/*.js`) обёрнуты в IIFE: имена внутри у них совпадают (`P`, `computeParts`, `build`…). Общее для комнат — в `rooms/common.js` (`roomKit`); правка, одинаковая для всех комнат, делается там.
- Карта файлов — в README.

## Чтение файлов
- `src/decors.js` (3,4 МБ фото в base64) и `index.html` целиком не читать: искать grep'ом и читать нужные строки.

## Коммиты
- Сообщение коммита — одна строка: без описания и без `Co-Authored-By`.
