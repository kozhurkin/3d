# 3d

## Сборка
- `index.html` — собранный файл (страницы из `src/` вшиты в него строками). Руками его не править: все правки только в `src/`.
- После любой правки в `src/` сразу запускать `npm run build` и проверить в Node, что изменение попало в `index.html`. Пользователь смотрит результат в `index.html`.

## Коммиты
- Сообщение коммита — одна строка: без описания и без `Co-Authored-By`.

## Чтение файлов
- Никогда не читай целиком `src/hall.html` и `src/bath.html` (по ~1000–1100 строк, ~36k токенов каждый). Найди нужное поиском (Grep), затем читай только нужные строки (Read с `offset`/`limit`).
