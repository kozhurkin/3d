# План: улучшения после декомпозиции

Что набралось по ходу декомпозиции кода комнат (план `REFACTOR.md` выполнен и удалён, он в git): странности, лишняя работа, разнобой в коде комнат и проверках.

## Правила

- Один шаг — один коммит, затем отчёт и вопрос; следующий шаг только после «да».
- После шага с правкой в `src/`: `npm run build`, полный `npm run check`. Новое поведение — новые проверки.
