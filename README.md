# 3d

Параметрическая 3D-модель квартиры со шкафами: планировка, прихожая, санузел, кухня.

Модель одна: стены, двери, окно и шкафы всех комнат в одной сцене. Вкладки — виды этой сцены. На «Планировке» правятся размеры стен, во вкладках комнат — шкафы. Переход между вкладками — перелёт камеры.

`index.html` — собранная модель одним файлом. Исходники в `src/`. Сборка: `npm run build`, проверка: `npm run check`.

## Исходники

| Файл | Что в нём |
|------|-----------|
| `src/shell.html` | Вкладки и iframe с приложением. При сборке сюда встраиваются декоры и само приложение. |
| `src/app.html` | Приложение: разметка, стили, порядок модулей. |
| `src/panels/*.html` | Панели вкладок (`plan`, `kitchen`, `bath`, `hall`) и общий блок «Свет и цвет стен» (`shared`). |
| `src/js/apartment.js` | Размеры квартиры `A` → стены `WALLS`, комнаты `ROOMS`, габарит `BOX`. Проверка размеров `aptProblems`. |
| `src/js/engine.js` | Renderer, сцена, камера (орбита, панорама, пинч), солнце, мини-вид, клики по дверям. |
| `src/js/walls.js` | Стены, двери, окно, полы и названия комнат. Обрезка стен рамкой вида, перелёт стен. |
| `src/js/views.js` | Виды и их настройки, общие настройки, переключение вида и перелёт. |
| `src/js/plan.js` | Вид «Планировка»: размерные линии, ракурсы, ползунки размеров стен. |
| `src/js/furniture.js` | Общее для шкафов: текстуры декоров, детали → 3D, отделка, срез и след шкафов, меню образца. |
| `src/js/rooms/*.js` | Комнаты: детали шкафов (`computeParts`), сборка, ракурсы, панель, отделка, деталировка. |
| `src/decors.js` | Декоры: фото в base64 (3,4 МБ) и палитры. |
| `tools/smoke.js` | Проверка в Node, без браузера. В `tools/fixtures/` — эталоны деталей шкафов из старых вкладок. |

## Настройки в браузере (`localStorage`)

| Ключ | Что | Когда сохраняется |
|------|-----|-------------------|
| `apt-model-v1` | `A` — размеры стен | кнопкой на «Планировке» |
| `apt-shared-v1` | общие: свет, цвет стен, перелёт | сразу |
| `apt-view-<вид>-v1` | настройки вида: режим и высота среза стен, двери, размерные линии, рамка | сразу |
| `apt-<комната>-v2` | `P` и `FIN` шкафа комнаты | кнопкой «Настройки по умолчанию» |
