# 3d

Параметрическая 3D-модель квартиры со шкафами: планировка, прихожая, санузел, кухня и обход квартиры от первого лица.

Модель одна: стены, двери, окно и шкафы всех комнат в одной сцене. Вкладки — виды этой сцены. На «Планировке» правятся размеры стен, во вкладках комнат — шкафы. Переход между вкладками — перелёт камеры.

`index.html` — собранная модель одним файлом. Исходники в `src/`. Сборка: `npm run build`, проверка: `npm run check`.

## Исходники

| Файл | Что в нём |
|------|-----------|
| `src/shell.html` | Вкладки и iframe с приложением. При сборке сюда встраиваются декоры и само приложение. |
| `src/app.html` | Приложение: разметка, стили, порядок модулей. |
| `src/panels/*.html` | Панели вкладок (`plan`, `kitchen`, `bath`, `hall`, `walk`) и общий блок «Свет и цвет стен» (`shared`). |
| `src/js/apartment.js` | Размеры квартиры `A` → стены `WALLS`, комнаты `ROOMS`, габарит `BOX`. Проверка размеров `aptProblems`. |
| `src/js/engine.js` | Renderer, сцена, камера (орбита, панорама, пинч), солнце, мини-вид, клики по дверям. |
| `src/js/walls.js` | Стены, двери, окно, полы и названия комнат. Обрезка стен рамкой вида, перелёт стен. |
| `src/js/views.js` | Виды и их настройки, общие настройки, переключение вида и перелёт. |
| `src/js/plan.js` | Вид «Планировка»: размерные линии, ракурсы, ползунки размеров стен. |
| `src/js/furniture.js` | Общее для шкафов: текстуры декоров, детали → 3D, отделка, срез и след шкафов, меню образца. |
| `src/js/rooms/common.js` | `roomKit(id, cfg)` — общее для комнат: сборка шкафов в сцене и их кадр, общие элементы панели (ракурсы, рамка, размеры, фасады, палитра, деталировка, настройки по умолчанию), `addView`. |
| `src/js/rooms/*.js` | Комнаты: размеры `P`, детали шкафов (`computeParts`), отделка, техника, размерные линии, ракурсы, свои элементы панели; остальное — через `roomKit`. |
| `src/js/walk.js` | Вид «Обход»: от первого лица, W A S D и мышь (захват указателя, Esc или правая кнопка — отпустить), прыжок, присед (Ctrl или C); стены (при любом их виде), закрытые двери и шкафы не пускают, «Без дверей» — проёмы свободны; потолок (над стенами в полную высоту, в «Разрезе» — пока камера в квартире) и широкий угол камеры только здесь. В панели — высота камеры, вид стен (в «Разрезе», как на плане, внешние стены убираются, когда камера снаружи), двери и общий блок «Цвет стен» (с галочкой «Контур стен» — одна для всех вкладок), «Свет». |
| `src/decors.js` | Декоры: фото в base64 (3,4 МБ) и палитры. |
| `tools/smoke.js` | Проверка в Node, без браузера: `npm run check`, часть — `npm run check -- kitchen`, список проверок — `--list`. |
| `tools/smoke/harness.js` | Обвязка проверки: заглушка THREE, маленький DOM, `runPage`, помощники. |
| `tools/smoke/*.js` | Проверки по частям: `app` (план, размеры стен, shell), `kitchen`, `bath`, `hall`, `flight`, `walk`. В `tools/fixtures/` — эталоны деталей шкафов из старых вкладок. |

## Настройки в браузере (`localStorage`)

| Ключ | Что | Когда сохраняется |
|------|-----|-------------------|
| `apt-model-v1` | `A` — размеры стен | кнопкой на «Планировке» |
| `apt-shared-v1` | общие: свет, цвет стен, перелёт | сразу |
| `apt-view-<вид>-v1` | настройки вида: режим и высота среза стен, двери, размерные линии, рамка | сразу |
| `apt-<комната>-v2` | `P` и `FIN` шкафа комнаты | кнопкой «Настройки по умолчанию» |
