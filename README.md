# 3d

Параметрическая 3D-модель квартиры со шкафами: планировка, прихожая, санузел, кухня и обход квартиры от первого лица.

Модель одна: стены, двери, окно и шкафы всех комнат в одной сцене. Вкладки — виды этой сцены. На «Планировке» правятся размеры стен, во вкладках комнат — шкафы. Переход между вкладками — перелёт камеры.

`index.html` — собранная модель одним файлом. Исходники в `src/`. Сборка: `npm run build`, проверка: `npm run check`.

## Исходники

| Файл | Что в нём |
|------|-----------|
| `src/shell.html` | Вкладки и кнопка «Скачать 3D-модель» в одну строку (не влезают — открытая вкладка и меню остальных), iframe с приложением. При сборке сюда встраиваются декоры и само приложение. |
| `src/app.html` | Приложение: разметка, стили, порядок модулей. Модуль может быть папкой: `<script src="js/…/" data-files="a b c" data-export="имя">` — сборка склеивает её файлы в этом порядке в одну область видимости (`build.js`: `folderModule`). |
| `src/panels/*.html` | Панели вкладок (`plan`, `kitchen`, `bath`, `hall`, `walk`) и общий блок «Свет и цвет стен» (`shared`). |
| `src/js/apartment.js` | Размеры квартиры `A` → стены `WALLS`, комнаты `ROOMS`, габарит `BOX`. Проверка размеров `aptProblems`. |
| `src/js/engine.js` | Renderer, сцена, камера (орбита, панорама, пинч), солнце, мини-вид, клики по дверям и по предметам со своим действием (`userData.click`: светильник над обеденным столом меняет модель, полка над ним — тоже (трёхъярусная ↔ оливковая с ящиками), полка над письменным — навесная HEMNES ↔ доска на кронштейнах в трёх цветах, угловой шкаф и антресоль — цвет, у каждого свой: белый ↔ Диамант серый U963 ST9, задние стенки шкафа из ЛДСП — тоже свой); «i» у предмета, на котором задержался курсор (`userData.info`), и карточка с его описанием (у того, что продаётся, — цена и ссылка на магазин, у собранного из нескольких товаров — строка на каждый; у того, что бывает в нескольких вариантах, — номер варианта (1/2) и ссылка «Следующий вариант →»). |
| `src/js/walls.js` | Стены (и низкие, со своей высотой `h`: ступенька в душ), двери (у двери санузла добор и наличники; квадратные ручки обеих дверей — `leverHandle`), окно, полы и названия комнат. Обрезка стен рамкой вида, перелёт стен, вид стен (`Wm`: «Контуры» — `edges`, «Следы» — `feet`); в `fade` вида стена прячется по своей стороне или вместе с другой стеной (по её id). |
| `src/js/views.js` | Виды и их настройки, общие настройки, переключение вида и перелёт. |
| `src/js/plan.js` | Вид «Планировка»: размерные линии, ракурсы, ползунки размеров стен, галочки расстановки (рабочий стол впритык к стене, задняя стенка шкафа из ЛДСП — хранятся в `A` с размерами). |
| `src/js/furniture.js` | Общее для шкафов: текстуры декоров, детали → 3D, отделка, срез и след шкафов, меню образца. |
| `src/js/rooms/common.js` | `roomKit(id, cfg)` — общее для комнат: сборка шкафов в сцене и их кадр, общие элементы панели (ракурсы, рамка, размеры, фасады — переключатель двигает только фасады шкафов, не то, что помечено `loose`: техника и мебель кухни, палитра, деталировка, настройки по умолчанию), `addView`. |
| `src/js/rooms/*.js`, `src/js/rooms/<комната>/` | Комнаты: размеры `P`, детали шкафов (`computeParts`), отделка, техника, размерные линии, ракурсы, свои элементы панели; остальное — через `roomKit`. Комната-папка — один модуль из файлов, порядок — в `app.html`. |
| `src/js/rooms/kitchen/` | Кухня у кухонной стены: |
| `…/kitchen/index.js` | Заголовок, `P` (размеры шкафов), `TB` (обеденный стол). |
| `…/kitchen/cabinets.js` | Детали шкафов (`computeParts`), размеры от плана (`fromModel`, `clamp`), отделка `FIN`. |
| `…/kitchen/info.js` | Карточки «i» кухни (`INFO`). |
| `…/kitchen/dining.js` | Обеденный стол и где он стоит (`placeDining`, `tableRoom`). |
| `…/kitchen/pendant.js` | Светильник над столом, три модели (`LAMPS`). |
| `…/kitchen/chairs.js` | Стулья BERGMUND. |
| `…/kitchen/shelves.js` | Полка над столом: трёхъярусная или оливковая с ящиками. |
| `…/kitchen/appliances.js` | Техника: мойка, варочная, посудомойка, духовка, вытяжка, холодильник; `applDoor`, `slab`. |
| `…/kitchen/view.js` | Размерные линии, ракурсы, панель, `living.attach`, `roomKit('kitchen', …)` — последним. |
| `src/js/rooms/living/` | Остальное в комнате кухни, кроме самой кухни. Строится вместе с кухней (`extra` в `kitchen/view.js`), в её осях; во вкладке «Кухня» не видно — только на «Планировке» и в «Обходе». Один модуль `living` из файлов (порядок — в `app.html`): |
| `…/living/index.js` | Заголовок, что берётся у кухни (`attach`), `smooth`. |
| `…/living/info.js` | Карточки «i» всего, что здесь: `INFO`, `cm`, `ozon`, товары шкафа. |
| `…/living/desk.js` | Письменный стол HEMNES с надстройкой и полкой над ней (навесная HEMNES или доска на кронштейнах). |
| `…/living/chair.js` | Кресло MILLBERGET. |
| `…/living/macbook.js` | MacBook на столе. |
| `…/living/vitrine.js` | Витрина HEMNES или книжный стеллаж на её месте. |
| `…/living/wardrobe.js` | Угловой шкаф с доп. секциями, ЛДСП-задниками, зеркалом и вешалкой; антресоли. |
| `…/living/rack.js` | Металлические стеллажи у правой стены. |
| `…/living/sofa.js` | Полка над диваном и угловой диван-кровать. |
| `…/living/radiator.js` | Радиатор под подоконником (в его материале; идёт за высотой окна). |
| `…/living/api.js` | `const living={…}`: что отдаётся кухне — `attach`, порядок сборки, препятствия для обхода, ключи групп. |
| `src/js/walk.js` | Вид «Обход»: от первого лица, W A S D и мышь (захват указателя, Esc или правая кнопка — отпустить), прыжок, присед (Ctrl или C); на сенсорном экране — стик под пальцем в левом нижнем углу сцены (квадрат в треть её ширины; скорость по отклонению), в остальной части — взгляд (вдвое быстрее мыши), тап — дверь, кнопок «i» и мини-вида нет; стены (при любом их виде), закрытые двери и шкафы не пускают (стулья у обеденного стола — пускают), «Без дверей» — проёмы свободны; потолок (белый при любом цвете стен; над стенами в полную высоту, в «Разрезе» — пока камера в квартире) и широкий угол камеры только здесь. В панели — высота камеры, вид стен (в «Разрезе», как на плане, внешние стены убираются, когда камера снаружи), двери и общий блок «Цвет стен» (с галочкой «Контур стен» — одна для всех вкладок), «Свет». |
| `src/js/export.js` | Экспорт сцены в `.glb` (glTF 2.0) для кнопки справа от вкладок: видимые сетки без света, линий и подписей; непрозрачные текстуры — JPEG. Экспортёр three.js (r128) грузится с jsDelivr при первом нажатии. |
| `src/decors.js` | Декоры: фото в base64 (3,4 МБ) и палитры. |
| `tools/smoke.js` | Проверка в Node, без браузера: `npm run check`, часть — `npm run check -- kitchen`, предмет части-папки — `npm run check -- living/sofa`, список проверок — `--list`. |
| `tools/smoke/harness.js` | Обвязка проверки: заглушка THREE, маленький DOM, `runPage`, помощники; в самой странице — `tt` для кода в `p.run(...)` (`PAGE_KIT`: предмет вида по ключу `userData`, его детали, габарит, мм, двери). |
| `tools/smoke/*.js` | Проверки по частям: `app` (план, размеры стен, shell), `kitchen`, `bath`, `hall`, `flight`, `walk`. |
| `tools/smoke/living/` | Проверки `living` по предметам — файлы как в `src/js/rooms/living/`; `index.js` подключает их по порядку. |

## Настройки в браузере (`localStorage`)

| Ключ | Что | Когда сохраняется |
|------|-----|-------------------|
| `apt-model-v1` | `A` — размеры стен и галочки расстановки | кнопкой на «Планировке» |
| `apt-shared-v1` | общие: свет, цвет стен, перелёт | сразу |
| `apt-view-<вид>-v1` | настройки вида: режим и высота среза стен, двери, размерные линии, рамка | сразу |
| `apt-<комната>-v2` | `P` и `FIN` шкафа комнаты | кнопкой «Настройки по умолчанию» |
