# План: декомпозиция кода комнат

Цель — чтобы задача про один предмет читала его файл (5–10 КБ) и его проверки, а не 65–80 КБ кода комнаты и столько же тестов: меньше токенов на задачу, правки не задевают соседей.

## Исходная точка (2026-11-21)

| Файл | Размер |
|------|--------|
| `src/js/rooms/living.js` | 81 КБ, 864 строки (строки до 775 символов) |
| `src/js/rooms/bath.js` | 71 КБ |
| `src/js/rooms/kitchen.js` | 66 КБ |
| `tools/smoke/living.js` | 79 КБ, 16 проверок |
| `tools/smoke/bath.js` | 64 КБ, 21 проверка |
| `tools/smoke/kitchen.js` | 54 КБ, 21 проверка |

Полный `npm run check` — 82 с, из них `app` ≈ 40 с и `walk` ≈ 45 с; остальные части 1–9 с.

## Правила

- Один этап — один коммит, затем отчёт и вопрос; следующий этап только после «да».
- После каждого этапа: `npm run build`, полный `npm run check`.
- Этапы разрезки код не меняют: собранный `index.html` должен остаться **байт в байт прежним** (`git diff --quiet index.html`). Исправления и упрощения — отдельными коммитами, не вместе с переносом.

## Не делаем

- ES-модули и бандлер — переписывание всего ради того же, что даёт склейка папки в `build.js`.
- Массовое переформатирование длинных строк — шум в истории; строки переносятся, когда трогаем их код.
- Вынос геометрических комментариев — они и объясняют, что где стоит.
