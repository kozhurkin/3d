# engelsa

- Отдельный проект одной комнаты: правки только внутри `engelsa/`, правила основного проекта (`../CLAUDE.md`) про сборку и проверку — те же, но команды — из этой папки.
- `index.html` собирается из `src/` (`npm run build`), руками не править; после правки в `src/` — `npm run check` (собирает сам).
- Ключи `localStorage` — только `eng-…`, чтобы не пересекаться с основным проектом.
- Размеры комнаты — `APT_A` в `src/js/apartment.js`; главные — данности (стены, потолок, положение проёмов как их меряли в комнате), остатки считаются в `apartment()`.
