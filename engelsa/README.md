# Комната на Энгельса

Отдельный проект одной комнаты. Ядро взято из основного проекта (`../src`): движок, стены с проёмами, дверь с наличниками, окно, виды с перелётом, обход от первого лица, размерные линии. Квартира, шкафы и декоры не взяты.

Ничего вне папки `engelsa` не читает и не пишет; в браузере хранит настройки под своими ключами `eng-…` (у основного проекта — `apt-…`).

`index.html` — собранный файл, руками не править. Сборка: `npm run build`, проверка: `npm run check` (сначала собирает сам). Команды — из папки `engelsa`.

| Файл | Что в нём |
|------|-----------|
| `src/shell.html` | Вкладки «Комната» и «Обход», кнопка «Скачать 3D-модель», iframe с приложением. |
| `src/app.html` | Приложение: разметка, стили, порядок модулей. |
| `src/panels/*.html` | Панели вкладок (`plan` — «Комната», `walk`) и общий блок «Свет и цвет стен» (`shared`). |
| `src/js/apartment.js` | Размеры комнаты `A` → стены `WALLS`, комната `ROOMS`, габарит `BOX`; проверка размеров `aptProblems`. |
| `src/js/engine.js` | Renderer, сцена, камера, солнце, мини-вид, клики по двери. |
| `src/js/walls.js` | Стены, окно, дверь (коробка, наличники, ручки), пол и название комнаты. |
| `src/js/views.js` | Виды, их настройки, перелёт между вкладками. |
| `src/js/plan.js` | Вкладка «Комната»: размерные линии, ракурсы, ползунки размеров. |
| `src/js/walk.js` | «Обход»: от первого лица, W A S D и мышь. |
| `src/js/export.js` | Экспорт сцены в `.glb`. |
| `tools/smoke.js`, `tools/smoke/` | Проверка в Node без браузера: `app`, `walk`. |

## Комната

Короткая стена с дверью 2710 (и стена с окном напротив), боковые стены 4797 (13 м² / 2710), потолок 3060. Дверь: 800 между наличниками по 70, правый наличник в 1570 от правого угла. Окно по центру стены напротив двери: ширина 1200, от 900 до 2950 от пола. Что не задано и взято условно — в панели «Комната», «Нужно уточнить».
